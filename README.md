MovieLens 100k Recommender System

Проєкт реалізує повний методологічно чистий пайплайн рекомендаційної системи на основі набору даних MovieLens 100k (100 000 оцінок, 943 користувачі, 1682 фільми, розрідженість матриці 93.70%).

Структура дослідження
1. Попередня обробка та аналіз якості даних: автоматичне завантаження датасету, валідація цілісності, перевірка на відсутність пропусків (NaN), дублікатів та узгодження типів даних.
2. Розвідувальний аналіз (EDA): аналіз розподілу оцінок, рейтингу популярності фільмів, активності користувачів, розподілу середніх балів та візуалізація фрагмента матриці взаємодій (User-Item Heatmap 30×30).
3. Побудова та порівняння парадигм колаборативної фільтрації:
   - Memory-Based: User-Based KNNWithMeans та Item-Based KNNWithMeans (косинусна міра схожості).
   - Model-Based: SVD (матрична факторизація Саймона Функа).
4. Оцінка та тюнінг (без Data Leakage):
   - Ізоляція відкладеної тестової вибірки (80/20 train/test split) до початку будь-якої оптимізації.
   - Підбір оптимальних гіперпараметрів SVD через GridSearchCV (3-fold cross-validation) виключно всередині тренувального набору (train_data).
   - Розрахунок похибок прогнозування (RMSE, MAE) та метрик ранжування (Precision@5, Recall@5) на відкладених тестових взаємодіях.
5. Генерація та системний аналіз якості рекомендацій:
   - Перенавчання фінальної моделі final_svd на 100% спостережень датасету.
   - Формування персональних списків непереглянутих фільмів Top-5.
   - Оцінка рекомендацій за кількісними метриками: Diversity (Intra-List Distance на базі косинусної відстані жанрових векторів), Novelty (інформативність у бітах на базі частоти у тренувальному сеті) та Catalog Coverage для когорти користувачів.
